### 1. 温度
- 温度を下げると、応答のランダム性が減り、同じ入力に対する出力の再現性・一貫性が高まります。
- 出力の一貫性を下げたり上げたりするために、最初に調整すべきモデル パラメーター

### 2. ペナルティ
- 頻度ペナルティ: 同一トークンの繰り返しを抑える調整
- 存在ペナルティ: 新しい話題の出現を促す調整

### 3. マルチパートユーザーメッセージ
- テキストと画像を1つのユーザーメッセージにまとめて送信できる形式

### 4. Azure Content Understanding
- プロジェクト作成の GUI ツール
- ドキュメント理解・コンテンツ理解を支援する統合ツール
- 標準モード：単一ファイル
- Proモード：複数ファイルの同時処理と多段推論

### 5. Work IQ
- Microsoft 365 のコンテキスト インテリジェンス層
- 組織の働き方の文脈をエージェントに提供する

### 6. スキルセット（skillset）
- AIスキルによる「エンリッチ処理」の手順を定義するリソース
    - エンリッチ処理 : 데이터나 문서에서 의미있는 정보를 추출해 데이터를 강화하는 과정
- OCR（Optical Character Recognition）やエンティティ抽出などの強化ステップをまとめる

### 7. Azure AI Search
- リソースの役割の区別
    - スキルセット : AIエンリッチ処理の手順定義、
    - データソース : 取り込み元、
    - インデクサー : 両者を結ぶ実行単位
- シノニムマップ（Synonym Map）
    - 異なる語句や表現が同じ意味を持つことを定義するリソース

### 8. Foundry Tools
##### 8-1. Rest API
- Ocp-Apim-Subscription-Key：リクエストにキーを付与するために使用するHTTPヘッダー

### 9. 埋め込みモデル（embedding model）
- テキストをベクトルに変換するモデル

### 10. キャプション生成
- 画像に対して、簡潔な説明や詳細な説明を生成する機能

### 11. マネージド ID
- Microsoft Entra ID が発行・管理する ID で、シークレットをコードに保存せずトークンベースでリソースにアクセスでき、キーのローテーション運用も不要

### 12. Shared Access Signature
- 有効期限付きトークン文字列を発行する仕組みで、依然として資格情報の生成・配布・更新が必要

### Python
- AIProjectClient 
    - PythonアプリからFoundryプロジェクトへ接続し、ネイティブなプロジェクト操作を行うために使用するクライアントクラス
    `from azure.ai.projects import AIProjectClient`

### AI Agent
- 操作の事後追跡・規制対応
    - トレース ログと実績メタデータ、および承認ワークフローを用いた監査により、エージェントの各操作の時刻・内容・根拠を後から追跡できます
