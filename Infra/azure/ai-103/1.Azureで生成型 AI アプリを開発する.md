# 1. Azureで生成型 AI アプリを開発する
## 1-1. Microsoft Foundry
### 1-1-1. デプロイの種類
- Global Standard
    - 일반적인 워크로드에 적합
    - 토큰단위 비용청구
    - 가장 높은 할당량(쿼터) 제공
- Global Provisioned
    - 예측 가능한 높은 처리량이 필요할 때 미리 예약된 고정 처리량(PTU : Provisioned Throughput Unit) 기반으로 예약
- Global Batch
    - 24시간 이내에 처리해도 되는 대규모 비동기 작업적합
    - 요금할인 혜택있음
- Data Zone
    - 데이터가 특정 데이터 영역(EU, 미국 등) 내에만 머물러야 하는 컴플라이언스(법/규정/정책) 시나리오에 선택
